## 一、开工前的 5 分钟检查

- **差商**：函数在 a 到 a+h 之间的平均变化率是 (f(a+h) − f(a))/h，关键限制是 h ≠ 0。
- **极限**：导数仍是极限，因此必须先化简差商，不能直接代 h = 0 得到 0/0。
- **连续**：函数极限存在且等于函数值才算连续；本周会问连续能否推出可导。
- **复合函数**：先识别内层和 outermost operation，外层规则先写在最外面。
- **定义域**：所有求导结果都受原函数定义域约束，约分不能补回被删掉的点。

知识依赖可压缩成：

Week 1 极限与连续
→ 差商极限和切线斜率
→ 基本求导规则
→ 链式法则
→ 反函数、隐函数、参数曲线
→ 导数符号与函数图形
→ 多变量方向导数（非考试）

### 2.2 三个枢纽

1. **差商极限**：所有求导公式都从它产生。切线斜率、瞬时速度和后面前沿技巧都围绕它。
2. **链式法则**：复合、隐函数、参数曲线、对数求导都会反复使用它。
3. **导数符号**：求导只是工具，真正分析函数要看 f′ 的零点和正负，再用 f″ 判断弯曲。

### 2.3 与 Week 1 的三条联系

- 函数极限提供了 ε-δ 语言；本周导数则把“差商的极限”当作研究对象。
- Week 1 已证明可导所依赖的极限运算和连续性；本周要区分“连续”和“可导”。
- Week 1 的函数定义域和复合函数是本周所有求导结果必须保留的边界。

## 三、逐条精讲

### 3.0 推导断点协议

遇到“这一步凭什么”时，固定在当前一行做五件事：

1. **定位**：抄下该式。
2. **归类**：定义、已证定理、代数恒等、隐含前提。
3. **补式**：展开括号、约去因式或补出中间极限。
4. **查前提**：分母是否非零、内层是否可导、是否仍遵守原定义域。
5. **收口**：写出“因为……所以……”。

单步时间盒 3 分钟。遇到计算卡点，先检查是否有可约公共因式和定义域限制。

### 3.1 平均变化率与导数

> **Definition 4.1.** The average rate of change of f from a to a+h is (f(a+h) − f(a))/h.

> **Definition 4.2.** f is differentiable at a if the finite limit
>
> f′(a) = lim h→0 (f(a+h) − f(a))/h
>
> exists.

**中文**：平均变化率是两点的割线斜率；让 h 趋近 0，割线趋近切线，极限若存在就是导数。

**动作**：先用定义证明时，展开 f(a+h)，约去 f(a)，再把分子中能提取的 h 约掉。

例 4.4：

((a+h)² − a²)/h = (2ah+h²)/h = 2a+h → 2a。

**坑**：不能一开始令 h=0，因为原差商里 h≠0。约分合法是因为在去心过程中 h≠0。

来源：p.3–5，定义 4.1–4.2，例 4.3–4.5。

### 3.2 可导与连续

> **Theorem 4.7.** If f is differentiable at an interior point a, then f is continuous at a.

**凭什么**：f(x) − f(a) = [(f(x) − f(a))/(x−a)](x−a)；第一因子有极限 f′(a)，第二因子趋于 0，所以差趋于 0。

**不能反推**：|x| 在 0 连续，但左右差商分别趋于 −1 和 1，导数不存在。

来源：p.5–6，定理 4.7，例 4.8。

### 3.3 eˣ、sin x 与 cos x

标准极限：

(eʰ − 1)/h → 1；sin h/h → 1；(cos h − 1)/h → 0。

这些极限推出：

(eˣ)′ = eˣ；(sin x)′ = cos x；(cos x)′ = −sin x。

**动作**：先利用函数恒等式把差商拆成“一个与 x 有关的部分 × 标准极限”。

**坑**：L’Hôpital 法则本身使用这些导数公式，所以不能用它反过来证明这几个基础极限，否则循环论证。

来源：p.7–8，例 4.9–4.11，命题 4.10，注 5.7。

### 3.4 基本求导工具

> **Theorem 4.12.** For x>0, (xʳ)′ = r xʳ⁻¹; also (eˣ)′ = eˣ; (log x)′ = 1/x; (sin x)′ = cos x; (cos x)′ = −sin x; (tan x)′ = sec²x.

规则：

- 线性：(cf+dg)′ = cf′+dg′。
- 乘积：(fg)′ = f′g+fg′。
- 商：(f/g)′ = (f′g−fg′)/g²，要求 g(x)≠0。

**动作**：多项式逐项求导；乘积和商先确认最外层结构，再套相应法则。

例 4.25：

(x² cos 3x)′ = 2x cos 3x − 3x² sin 3x。

来源：p.8–11，定理 4.12–4.17，例 4.14–4.20。

### 3.5 链式法则与混合求导

> **Theorem 4.21.** If u is differentiable at x and v is differentiable at u(x), then
>
> (v ∘ u)′(x) = v′(u(x))u′(x).

**动作**：

1. 找最外层操作。
2. 先对外层求导，保留内层不动。
3. 再乘内层导数。
4. 若内层也复合，继续往内。

例 4.24：

(sin(e^{x²}))′ = cos(e^{x²})e^{x²}2x。

**坑**：漏乘内层导数是最高频错误；乘法和商与复合同时出现时，先看最外层。

来源：p.11–13，定理 4.21，例 4.22–4.27，Exercise 4.29。

### 3.6 反函数导数

> **Theorem 5.1.** If f is differentiable at a, f⁻¹ is continuous at b=f(a), and f′(a)≠0, then
>
> (f⁻¹)′(b) = 1/f′(a).

一般写法：

(f⁻¹)′(x) = 1/f′(f⁻¹(x))。

**动作**：先由 b=f(a) 找 a，再算 f′(a)，最后取倒数。

例 5.2：f(x)=x³，b=8，a=2，f′(2)=12，所以 (f⁻¹)′(8)=1/12。

**坑**：分母中的导数要在 a=f⁻¹(b) 处取值；f⁻¹ 不是 1/f；f′(a)=0 时定理不能用。

来源：p.15–18，定理 5.1，例 5.2–5.4，注 5.5。

### 3.7 L’Hôpital 法则

> **Theorem 5.6.** For a quotient f/g that has the indeterminate form 0/0 or ∞/∞, if f′/g′ has a limit L, then f/g has the same limit.

**使用前检查**：

- 是商式；
- 代入后是 0/0 或 ∞/∞；
- 附近满足可导和非零分母条件；
- 新的导数商确实有极限。

例 5.9：log x / x 在∞处为∞/∞，求导后 (1/x)/1→0。

**坑**：L’Hôpital 是极限定理，不是函数恒等式；0·∞、∞−∞、1^{∞} 等要先改写成商或指数形式。

来源：p.18–21，定理 5.6，例 5.8–5.15，注 5.7。

### 3.8 隐函数求导

关系 F(x,y)=0 在局部可以决定 y=y(x) 时，对两边关于 x 求导。

关键：

d(y²)/dx = 2y(dy/dx)；
d(xy)/dx = y + x(dy/dx)。

例 5.17：x²+y²=r² 给出 2x+2y y′=0，所以 y′=−x/y，前提 y≠0。

**动作**：先确认点在曲线上；再对每一项求导；最后收集含 y′ 的项。

**坑**：y 不是常数；x 与 y 同时出现的项要用乘积法则；在 y=0 处不能直接除以 y，应回原曲线判断竖直切线。

来源：p.22–23，例 5.17–5.18，注 5.19。

### 3.9 对数求导与变底指数

对 y>0：

ln y = ln(乘积/商/幂) = 各项对数之和。

再求导：

y′/y = 右侧对数导数，因此 y′ = y × 右侧对数导数。

例 5.21：

y=xˣ=e^{x ln x}，

y′ = xˣ(ln x+1)。

**坑**：当底数和指数都变化时，幂法则和指数法则都不单独适用；对数要求正数，必要时对 |y| 使用。

来源：p.24–25，例 5.20–5.22，Exercise 5.23。

### 3.10 参数曲线

> **Definition 5.24.** A parameterised curve is x=x(t), y=y(t) for t in an interval.

若 dx/dt≠0：

dy/dx = (dy/dt)/(dx/dt)。

**动作**：先算 dx/dt、dy/dt，再用参数 t 表示斜率；将 t 值代回求点坐标。

例 5.27：单位圆 x=cos t，y=sin t，sin t≠0 时 dy/dx=−cos t/sin t；t=0 处 dx/dt=0，应单独看竖直切线。

来源：p.25–28，定义 5.24，例 5.25–5.27，Exercise 5.28。

### 3.11 单调性、临界点与极值

- f′>0：严格递增。
- f′<0：严格递减。
- 驻点：f′(a)=0。
- 临界点：f′(a)=0 或 f′(a) 不存在。
- Fermat：内点可导极值必为驻点；驻点不一定极值。

**动作**：先找临界点，再用因式分解写导数符号表；闭区间最值还要比较端点。

例 6.8：f=x³−3x，f′=3(x−1)(x+1)，x=−1 是局部最大，x=1 是局部最小。

来源：p.29–30，定义 6.2–6.4，定理 6.5，例 6.6、6.8。

### 3.12 一阶与二阶导数判别

一阶判别：

- 左正右负：局部最大。
- 左负右正：局部最小。
- 两侧同号：不是局部极值。

二阶判别：在 f′(a)=0 且 f″(a)≠0 时，f″(a)>0 为局部最小，f″(a)<0 为局部最大；f″(a)=0 不能下结论。

来源：p.31–32，定理 6.7、6.9，例 6.10–6.11。

### 3.13 完整函数分析

顺序：

1. 定义域和截距。
2. f′ 的零点和不存在点。
3. 一阶导数符号与单调区间。
4. 极值坐标。
5. f″ 的凸凹与拐点候选。
6. 端点和无穷远处行为。

例 6.12：f=x³−3x 的临界点是 ±1，截距为 −√3、0、√3，x<0 凹、x>0 凸，两端分别趋于 −∞ 和 ∞。

**坑**：局部极值不等于全局最值；闭区间上还要检查端点。

来源：p.32–34，例 6.12–6.13。

### 3.14 求导方法选择

先看结构，后计算：

- 和/差：线性规则。
- 乘积：乘积法则。
- 商：商法则。
- 复合：链式法则。
- x 与 y 混在方程里：隐函数求导。
- 多个因式相乘/相除：可考虑对数求导。
- x=x(t)、y=y(t)：参数求导。
- 题目要求 first principles：必须从差商开始。

来源：p.34–36，例 6.15–6.19，Exercise 6.20。

### 3.15 偏导数（非考试）

> **Definition 13.1.** For f(x,y), the partial derivative with respect to x is
>
> ∂f/∂x = lim h→0 [f(a+h,b) − f(a,b)]/h.

对 x 求偏导时把 y 当常数；对 y 求偏导时把 x 当常数。

例 13.2：f=x²y+3xy²−4y，fₓ=2xy+3y²，f_y=x²+6xy−4。

来源：p.37–38，定义 13.1，例 13.2–13.3。

### 3.16 方向导数（非考试）

> **Definition 13.4.** For a unit vector u=(u₁,u₂),
>
> Dᵤf(a,b) = lim h→0 [f(a+hu₁,b+hu₂) − f(a,b)]/h.

沿方向 u 的直线取 t ↦ f(a+tu₁,b+tu₂)，再在 t=0 求普通导数。

例 13.5：f=x²+y²，在 (1,2)、u=(1/√2,1/√2) 方向，Dᵤf=3√2。

**坑**：方向向量必须是单位向量，否则数值会随向量长度缩放。

来源：p.38–39，定义 13.4，例 13.5。

## 四、问题二 · 漏洞自检

### 4.1 可导与连续方向写反

- **卡点**：看到函数连续就认为导数存在。
- **零基础版**：|x| 在 0 没有断点，但左坡是 −1，右坡是 1，没有一个共同切线斜率。
- **材料没交代**：定理 4.7 只给可导 ⇒ 连续；反例在例 4.8 中。

### 4.2 在差商中直接代 h=0

- **卡点**：一上来把 h=0 代入，得到 0/0 后停止。
- **零基础版**：平均变化率只定义在 h≠0；必须先展开并约去 h，再令剩余部分 h→0。
- **材料没交代**：讲义 p.4 已明确说明去心极限；风险在于抄公式时省略。

### 4.3 漏掉链式法则的内层导数

- **卡点**：把 (1+x²)⁵ 导数写成 5(1+x²)⁴。
- **零基础版**：外层幂的变化还受到内层 x² 变化的影响，必须再乘 2x。
- **材料没交代**：例 4.22 展示完整步骤；材料没有替读者检查每一层。

### 4.4 乘积和商直接求导再相乘/相除

- **卡点**：把 (fg)′ 写成 f′g′。
- **零基础版**：x·x=x²，左边导数是 2x，错误公式给 1，差得很远。
- **材料没交代**：注 4.28 给反例；乘积有两个“哪一项在变化”的来源。

### 4.5 反函数导数取错位置

- **卡点**：算 (f⁻¹)′(b) 时除以 f′(b)。
- **零基础版**：b 是 f 的输出，要先回到对应输入 a=f⁻¹(b)，再在 a 处求 f′。
- **材料没交代**：定理 5.1 的证明已说明 b=f(a)，但符号相近容易看漏。

### 4.6 L’Hôpital 用于非不定式

- **卡点**：看到分数就分别对分子分母求导。
- **零基础版**：2x−1 除以 x 在 x=1 得 1/1，根本不需要无穷比较，正确极限是 1。
- **材料没交代**：例 5.13 完整说明；规则只在 0/0、∞/∞ 等条件满足时使用。

### 4.7 隐函数求导把 y 当常数

- **卡点**：对 y² 求 x 导数只写 2y。
- **零基础版**：y 随 x 变化，所以链式法则要求 2y·y′。
- **材料没交代**：讲义用 y=y(x) 解释；如果直接抄公式会漏。

### 4.8 对数求导忽略正数条件

- **卡点**：对可能为负的 y 直接写 ln y。
- **零基础版**：对数只接受正输入；y 可能为负时要考虑 ln|y| 或先确认范围。
- **材料没交代**：p.25 提到 ln|y|，但需要读者理解原函数范围。

### 4.9 参数导数直接写 dy/dt

- **卡点**：题目问 dy/dx，却只给出 y′(t)。
- **零基础版**：dy/dt 是相对于参数 t 的速度，dy/dx 才是图形相对于横向变化的变化率。
- **材料没交代**：例 5.27 提醒 dx/dt=0 时必须单独讨论。

### 4.10 把 Fermat 定理当充分条件

- **卡点**：看到 f′(a)=0 就断言极值。
- **零基础版**：x³ 在 0 的导数为 0，但左侧负、右侧正，函数继续上升，没有极值。
- **材料没交代**：例 6.6 直接演示；Fermat 只给必要条件。

### 4.11 二阶导数为 0 就判无结论以外的东西

- **卡点**：f″=0 时擅自判定极值类型。
- **零基础版**：x⁴ 和 x³ 在 0 都有一阶、二阶导数为 0，却一个是极小、一个没有极值。
- **材料没交代**：例 6.11 示范必须回到一阶导数符号。

### 4.12 忽略定义域和端点

- **卡点**：约分或求导后把定义域扩大。
- **零基础版**：原函数在某个点没有定义，导函数公式即使在那里能算，也不能把该点塞回定义域。
- **材料没交代**：例 4.27 明确；最终答案必须回到原函数定义域。

## 五、问题三 · 出题人视角

第 1、3、5、7、9、13 题来自讲义官方练习，解答由本手册独立完成；其余为自造题。

### 1. 官方 Exercise 4.29 选做

求以下导数：

1. f(x)=(3x+1)⁵。
2. g(x)=e⁻²ˣ。
3. h(x)=ln(1+x²)。
4. p(x)=x²eˣ。

**解答**：

1. f′(x)=5(3x+1)⁴·3=15(3x+1)⁴。
2. g′(x)=e⁻²ˣ·(−2)=−2e⁻²ˣ。
3. h′(x)=2x/(1+x²)，定义域为全体实数。
4. p′(x)=2xeˣ+x²eˣ=xeˣ(x+2)。

**筛掉**：只会一个一个套公式，忽略复合内层导数，或把乘积写成 f′g′。

### 2. 自造：用定义求 x³ 的导数

**解答**：

[(a+h)³−a³]/h
= [3a²h+3ah²+h³]/h
= 3a²+3ah+h² → 3a²。

**筛掉**：把 h=0 直接代入原差商，或用幂法则却没有按要求走定义。

### 3. 官方 Exercise 5.16 选做

求：

1. lim x→0 (1−cos x)/x²。
2. lim x→0 (eˣ−1−x)/x²。
3. lim x→0⁺ x² ln x。

**解答**：

1. 为 0/0，求导一次得 sin x/(2x)；再用 sin x/x→1，结果 1/2。
2. 为 0/0，连续应用两次：eˣ−1 / 2x，再求导 eˣ/2→1/2。
3. 改写成 ln x/(1/x²)，为 −∞/∞；求导得 (1/x)/(−2x⁻³)=−x²/2→0。

**筛掉**：不检查不定式类型，或 ∞−∞、0·∞ 不先变形就用规则。

### 4. 自造：反函数导数

设 f(x)=x³+x。已知 f(1)=2，求 (f⁻¹)′(2)。

**解答**：f′(x)=3x²+1，f′(1)=4，所以 (f⁻¹)′(2)=1/4。

**筛掉**：在 2 这个输出处找 a，却直接算 f′(2)，或把逆函数当倒数。

### 5. 官方 Exercise 5.23 选做

求 y=x^{√x}，x>0。

**解答**：

ln y=√x ln x，

y′/y=ln x/(2√x)+√x/x=(ln x+2)/(2√x)。

所以 y′=x^{√x}(ln x+2)/(2√x)。

**筛掉**：把指数 √x 当常数，或底数 x 当常数。

### 6. 自造：隐函数求导

对 x²+xy+y²=7，在点 (1,2) 求 dy/dx 和切线。

**解答**：

2x+y+x y′+2y y′=0，

所以 y′=−(2x+y)/(x+2y)。在 (1,2) 得 y′=−4/5。

切线：y−2=−4/5(x−1)。

**筛掉**：忘记 xy 的乘积项，或没检查点确实在曲线上。

### 7. 官方 Exercise 5.28

x(t)=t²+1，y(t)=t³−3t。

求 t=−1,0,1 的点和方向；求 dy/dx；求 t=1 的切线；解释 t=0。

**解答**：

- t=−1：(2,2)；t=0：(1,0)；t=1：(2,−2)；t 增大时从左向右经过。
- dx/dt=2t，dy/dt=3t²−3。
- t≠0 时 dy/dx=(3t²−3)/(2t)。
- t=1 处点 (2,−2)，斜率 0，切线 y=−2。
- t=0 时 dx/dt=0、dy/dt=−3，公式分母为 0；曲线在该点有竖直切线 x=1。

**筛掉**：直接把 dy/dt 当 dy/dx，或在 dx/dt=0 处硬除。

### 8. 自造：函数极限与求导连续性

解释为什么“f 在 0 连续”不能保证“f 在 0 可导”。

**解答**：反例 f(x)=|x|。它处处连续；在 0 的右差商为 1，左差商为 −1，左右极限不同，所以导数不存在。

**筛掉**：把可导与连续当成等价，或只检查图像不断开。

### 9. 官方 Exercise 6.14

设 f(x)=x³−3x²−9x+5。

**解答**：

f′(x)=3x²−6x−9=3(x−3)(x+1)，驻点为 −1、3。

符号表：x<−1 时正，−1<x<3 时负，x>3 时正。

所以 x=−1 为局部最大，x=3 为局部最小。f″=6x−6，代 f″(−1)=−12、f″(3)=12 验证一致。

y 截距为 5；两端分别趋于 −∞ 和 +∞。

**筛掉**：只找驻点不判符号，或把局部极值当全局最值。

### 10. 自造：闭区间全局最值

在 [−2,3] 上求 f(x)=x³−3x 的全局最大和最小。

**解答**：临界点为 −1、1；检查候选 f(−2)=−2、f(−1)=2、f(1)=−2、f(3)=18。最大值为 18，在 x=3；最小值为 −2，在 x=−2 和 x=1。

**筛掉**：只看临界点，漏掉闭区间端点。

### 11. 自造：错用二阶判别

对 f=x⁴ 和 g=x³，在 0 处都有 f′(0)=g′(0)=0，且二阶导数也为 0。能判断极值类型吗？

**解答**：二阶判别无结论。x⁴ 在 0 是全局最小；x³ 在 0 不是极值。必须改用一阶导数符号或定义判断。

**筛掉**：把“无结论”误当成“没有极值”。

### 12. 自造：求导方法选择

不用计算，说明 f(x)=x e^{x²}/(1+x²) 的求导顺序。

**解答**：最外层是商，先用商法则；分子是 x 和 e^{x²} 的乘积，用乘积法则；e^{x²} 是复合，再对其用链式法则。

**筛掉**：从内往外乱套规则，或忽略最外层结构。

### 13. 官方 Exercise 6.20 选做

1. 用定义求 f(x)=x³ 的导数。
2. 对 f(x)=x³+x，已知 f(1)=2，求 (f⁻¹)′(2)。
3. 求 lim x→∞ x/eˣ，并说明规则前提。

**解答**：

1. 差商为 3a²+3ah+h²，令 h→0 得 3a²。
2. f′(1)=4，所以逆函数在 2 的导数为 1/4。
3. 分子分母都趋于无穷，可对商使用 L’Hôpital，得到 1/eˣ→0。

**筛掉**：不区分题目要求定义还是规则，或不检查极限形式。

### 14. 自造：偏导数与方向导数（非考试）

设 f(x,y)=x²y+3xy²−4y，在 (1,2) 求 fₓ、f_y；再沿单位向量 u=(1/√2,1/√2) 用一般方向变化解释它与偏导的区别。

**解答**：

fₓ=2xy+3y²，fₓ(1,2)=16；

f_y=x²+6xy−4，f_y(1,2)=9。

偏导数分别只沿水平 x 方向和竖直 y 方向改变输入；方向导数沿指定单位向量改变两个变量，衡量该方向上的局部变化率，因此通常与两个偏导数都不同。

**筛掉**：求 ∂f/∂x 时把 y 也当变量，或忘记方向向量需要单位长度。
