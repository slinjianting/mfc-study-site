## 3. 逐条精讲

### 3.1 原函数与不定积分

**英文原句**：An indefinite integral ∫f(x)dx=F(x)+C represents the family of antiderivatives on an interval I when F′=f.

**中文**：原函数在每个连通区间上可差任意常数；定义域断开时，各段常数可不同。

**公式**：

```text
∫2x dx = x² + C
∫1/x dx = log x + C₊ on x>0
∫1/x dx = log(−x) + C₋ on x<0
```

**动作**：找原函数；检查定义域；对答案求导验证。

**坑**：把 R∖{0} 的两支用一个常数合在一起。

**凭什么**：常数求导为 0；同一连通区间任意两个原函数只差常数。

### 3.2 换元与定积分边界

**英文原句**：Under the hypotheses of Theorem 10.2, ∫ₐᵇf(x)dx=∫αβf(t(y))t′(y)dy with a=t(α), b=t(β).

**中文**：换元必须同时改 integrand、微分和端点；有向积分自动处理递减换元的负号。

**公式**：

```text
∫2x(x²+1)³dx = (x²+1)⁴/4+C
∫₀¹x√(1−x²)dx = −1/2∫₁⁰u^{1/2}du = 1/3
```

**动作**：识别内层函数与导数因子；换全部变量；定积分同时换端点。

**坑**：换了 u 却保留旧边界；把 t′ 改成 |t′|。

**凭什么**：F(t(y)) 的链式导数是 f(t(y))t′(y)，再对两端用 Newton–Leibniz。

### 3.3 分部积分与重复分部

**英文原句**：For continuously differentiable u and v, ∫ₐᵇu v′dx=[uv]ₐᵇ−∫ₐᵇu′vdx.

**中文**：分部积分把乘积的导数负担转移；定积分必须保留 uv 边界项。

**公式**：

```text
∫x eˣdx = eˣ(x−1)+C
∫x²eˣdx = eˣ(x²−2x+2)+C
∫₀ᴿu v′dx = [uv]₀ᴿ−∫₀ᴿu′vdx
```

**动作**：选 u 使 u′ 更简单；选 v′ 使 v 易求；每次分部累加边界项。

**坑**：只检查公式合法，不检查剩余积分是否更难；improper 情形直接代∞。

**凭什么**：乘积法则 (uv)′=u′v+uv′ 积分并移项。

### 3.4 有理函数、除法与部分分式

**英文原句**：A rational function P/Q is proper if degP<degQ; an improper fraction is divided before partial fractions.

**中文**：先看分子分母次数，再按分母因子完整铺模板。

**公式**：

```text
(x²+1)/(x+1)=x−1+2/(x+1)
1/((x+1)(x+2))=1/(x+1)−1/(x+2)
```

**动作**：写原分母非零区间；除法到真分式；分解分母；列完整模板；求系数并合并验证。

**坑**：重复因子只写一次；不可约二次只写常数分子；跨极点直接代端点。

**凭什么**：多项式除法降低次数；实多项式分解决定部分分式模块。

### 3.5 有理原函数、极点和可去点

**英文原句**：Every real rational function has an elementary primitive on each interval where its original denominator is nonzero.

**中文**：原函数逐区间存在，但不能跨越极点直接拼接。

**公式**：

```text
∫1/(x−r)dx = log|x−r|+C
∫1/(x²+1)dx = arctan x+C
```

**动作**：线性项积成对数；不可约二次配方后分成对数与 arctan；跨极点拆 improper。

**坑**：约分后看起来连续不等于原函数补回缺点；log|x−1| 不能直接给跨 1 的积分。

**凭什么**：部分分式提供基本原函数；跨极点要检查两侧 improper 极限。

### 3.6 三角幂、三角换元与分支

**英文原句**：Odd trigonometric powers provide a derivative factor; all-even powers use reduction identities.

**中文**：奇次留一个因子换元，偶次用倍角降幂；根式用三角恒等式消去，但要选分支。

**公式**：

```text
sin²x=(1−cos2x)/2
cos²x=(1+cos2x)/2
x=sin t ⇒ sqrt(1−x²)=|cos t|
∫dx/sqrt(1−x²)=arcsin x+C
```

**动作**：先看幂次奇偶或根式结构；选换元或恒等式；反解时限制分支。

**坑**：全偶次仍硬找不存在的导数因子；忽略根号和反三角的绝对值。

**凭什么**：三角恒等式与链式法则把复杂 integrand 化为基本项。

### 3.7 双曲函数与对称性

**英文原句**：Hyperbolic functions satisfy cosh²x−sinh²x=1; on symmetric intervals, even functions double and odd functions cancel.

**中文**：双曲换元适合处理 1+x² 根式；奇偶对称需要对称区间和可积性。

**公式**：

```text
∫dx/sqrt(1+x²)=arsinh x+C
arsinh x=log(x+sqrt(1+x²))
∫−aᵃf=2∫₀ᵃf if f is even
∫−aᵃf=0 if f is odd
```

**动作**：识别 cosh²−sinh²；检查区间 [−a,a]；先验可积性再验奇偶。

**坑**：把双曲恒等式写成加号；用 1/x 当作对称性反例却没先判 improper。

**凭什么**：指数定义产生双曲恒等式；左半积分反射到右半后按奇偶相加或抵消。

### 3.8 存在性、初等表达与数值积分

**英文原句**：Continuity guarantees integrability on a finite closed interval, but not an elementary primitive.

**中文**：积分存在、能写成初等公式、能给出数值近似是三件不同的事。

**公式**：

```text
f∈C([a,b]) ⇒ f∈R([a,b])
```

**动作**：先检查可积性；尝试结构方法；没有初等公式时保留精确积分或说明数值近似。

**坑**：找不到原函数就断言积分不存在；给出小数却不说明误差和方法。

**凭什么**：Riemann 积分的存在性来自连续性与 Darboux 判据，不来自初等原函数。

### 3.9 方法选择与课程综合

**英文原句**：Integration methods are selected by structure, and complex problems may combine substitution, parts, partial fractions, identities and symmetry.

**中文**：先看定义域和最外层结构，再选首条方法；做完一步重新识别新结构。

**动作**：复合查换元；乘积查分部；有理式先除后拆；根式查三角/双曲；对称区间查奇偶。

**坑**：合法但让剩余积分更复杂的方法应立即停止；算完原函数还得回查定义域和误差。

**凭什么**：每种技术对应导数和代数结构，前提不满足或结构改变时必须重选。

### 3.10 标量线积分（非考试）

**英文原句**：For a parameterised curve, ∫_C f ds=∫ₐᵇf(γ(t))|γ′(t)|dt.

**中文**：参数速度把 dt 换算成曲线长度；同一几何曲线若被走两遍，线积分也重复。

**公式**：

```text
ds = |γ′(t)|dt
∫_C 1 ds = curve length
```

**动作**：写出参数化；计算速度；代入标量函数；按参数区间积分。

**坑**：忘记速度；不说明方向与重复描迹。

**凭什么**：参数运动 dt 产生的曲线距离元是速度乘 dt。

## 4. 问题二：漏洞自检

| 卡点 | 零基础版 | 材料没交代或提醒 |
| --- | --- | --- |
| 原函数 +C | 常数导数 0，所有曲线可上下平移 | 断开区间常数可不同 |
| 换元 | 链式法则反向，内层和微分都要换 | 定积分边界也换 |
| 递减换元 | 方向会带负号 | 不能把 t′ 改绝对值 |
| 分部积分 | 一部分求导，一部分先积分 | uv 边界项不能漏 |
| 有理函数 | 先除到真分式再拆 | 分母零点仍是定义域 |
| 部分分式 | 重复幂和二次因子全部出现 | 二次因子用线性分子 |
| 跨极点 | 左右 improper 分别检查 | 不能端点相减抵消 |
| 三角幂 | 奇次提供 du，偶次降幂 | 角度倍数要处理 |
| 三角换元 | 根号先出绝对值 | 反解要选分支 |
| 双曲 | cosh²−sinh²=1 | 符号与三角不同 |
| 奇偶对称 | 区间 [−a,a] 且函数可积 | 1/x 跨 0 不可直接抵消 |
| 非初等积分 | 存在和初等表达分开 | 数值误差要另给 |
| 方法选择 | 先结构后规则，算一步再判断 | 合法不等于有用 |
| 线积分 | ds 等于速度乘 dt，方向与重数重要 | 非考试 |

## 5. 问题三：出题人视角

### 手算

#### 1. 识别换元

**来源**：官方 Exercise 10.6，p.7。  
**题**：为含复合与导数因子的积分选择 u，并改写全部微分。  
**解答**：取内层函数为 u；把 x、dx 全部换成 u、du；积分后回代。  
**筛掉**：只换一两个 x，仍混用变量的人。

#### 2. 定积分换元

**来源**：官方 Exercise 10.7，p.7。  
**题**：用换元计算定积分并同时改变边界。  
**解答**：由换元关系映射上下界；在新变量中积分；若回代则使用旧边界。  
**筛掉**：换元后保留旧端点的人。

#### 3. 分部积分

**来源**：官方 Exercise 10.14，p.10。  
**题**：对多项式乘指数或三角函数使用分部积分。  
**解答**：多项式取 u，指数/三角取 v′；定积分保留 [uv] 边界项。  
**筛掉**：漏边界项或选择使积分更复杂的人。

#### 4. Improper 中的分部

**来源**：官方 Exercise 10.16，p.10。  
**题**：先写截断真积分，再使用分部并取极限。  
**解答**：所有含 R 的边界项保留到极限步骤。  
**筛掉**：直接把 ∞ 当端点的人。

#### 5. 部分分式原函数

**来源**：官方 Exercise 10.24，p.14。  
**题**：先检查真分式，再拆模板并积分。  
**解答**：除法、因式分解、完整模板、求系数、逐项积分、求导验证。  
**筛掉**：模板漏项或忽略原定义域的人。

### 给错解找错

#### 6. 定义域、极点与可去点

**来源**：官方 Exercise 10.25，p.14。  
**题**：解释约分后的连续性为什么不能恢复原分母零点。  
**解答**：定义域由原式决定；约分只改变已定义点的表达式。  
**筛掉**：把可去点误当原函数值的人。

#### 7. 三角幂与乘积

**来源**：官方 Exercise 11.5，p.17。  
**题**：选择换元或降幂恒等式。  
**解答**：奇次幂拆导数因子；全偶次幂用倍角降幂。  
**筛掉**：全偶次仍硬找单个因子的人。

#### 8. 根式与分支

**来源**：官方 Exercise 11.8，p.18。  
**题**：为含根式积分选择三角替换并写分支。  
**解答**：按 1−x²、1+x²、x²−1 匹配恒等式；反解时选合法分支并处理绝对值。  
**筛掉**：只写替换、不处理反函数主值的人。

### 概念追问

#### 9. 双曲积分

**来源**：官方 Exercise 11.11，p.21。  
**题**：用双曲定义证明 cosh²−sinh²=1，并求相关原函数。  
**解答**：代入指数定义；必要时令 x=sinh t；可得到 arsinh 或对数表达。  
**筛掉**：把双曲恒等式符号写错的人。

#### 10. 奇偶与对称

**来源**：官方 Exercise 11.15，p.23。  
**题**：判断对称区间积分的两倍或抵消。  
**解答**：先验 [−a,a] 和可积性，再验 f 的奇偶性；跨极点 1/x 不可直接消项。  
**筛掉**：只看图形对称、不看前提的人。

#### 11. 自造：方法诊断

**来源**：自造，不是官方题。  
**题**：为什么“公式能套”不等于“第一步应该用”？  
**解答**：方法要降低剩余复杂度；合法但更复杂的路径应停止。  
**筛掉**：只认公式名称的人。

#### 12. 自造：部分分式定义域

**来源**：自造，不是官方题。  
**题**：约分后表达式处处有值，为什么原定义域仍缺一个点？  
**解答**：原式分母为零即无定义；约分只提供限制域上的等价表达式。  
**筛掉**：用化简后的公式扩大原定义域的人。

### 综合

#### 13. 自造：课程综合

**来源**：自造，不是官方题。  
**题**：说明 FTC、Taylor 余项和 improper 极限在同一积分问题中的分工。  
**解答**：FTC连接原函数与定积分；Taylor余项控制数值误差；improper极限检查端点收敛。  
**筛掉**：只算原函数而忽略存在性和误差的人。

#### 14. 自造：重复线积分轨迹

**来源**：自造，不是官方题，Chapter 14 非考试。  
**题**：同一圆用 [0,2π] 与 [0,4π] 参数化，常数函数线积分为何不同？  
**解答**：线积分按参数轨迹累计；4π 区间把圆走两遍。  
**筛掉**：只把曲线看作几何集合、忽略参数化重数的人。
