集合语言

成员、子集、并交差、补集、De Morgan 律和笛卡尔积构成全部记号基础。

数系与区间

数系层层包含；区间是实数线的一段，端点是否包含必须看清。

界、最大值、上确界

p.6–7

上界不必属于集合；最大值必须属于集合；上确界是最小的上界。

距离与三角不等式

p.8–9

绝对值和距离负责把“靠近”写成不等式；三角不等式负责拆分误差。

函数、像与原像

p.10

像问输入到了哪里；原像问哪些输入落进指定输出集合。

复合与自然定义域

p.11, 13

先满足内层，再满足外层；所有限制必须同时成立。

单射、满射、双射

p.11–13

逆函数存在当且仅当原函数是双射；严格单调能推出单射。

初等函数

p.13

多项式与三角函数的自然定义域是 R；根号、对数、分母各有额外限制。

可数与不可数

p.14–15

N、Z、Q 可数；R 不可数。可数有限集也算可数。

数列与 epsilon-N

p.16–19

收敛要求最终整条尾部进入任意容差带，不是“经常接近”。

极限结构、法则与夹逼

p.20–24

极限唯一；收敛必有界；加减乘除、保序和夹逼都从定义证明。

发散到无穷

p.25–26

趋于 +∞ 是“超过任意水平 M”，并不表示有一个实数极限。

聚点与函数极限

p.27–30

必须先有聚点；极限考察去掉 a 后的邻域，与 f(a) 无关。

函数极限法则与代入

p.31–34

四则运算要求有限极限；代入前检查分母；0/0 时可约去公共因式。

连续性与间断点

p.34–39

连续要求函数在 a 有定义、极限存在，并且极限等于函数值。

连续函数性质与无穷极限

p.38–43

初等函数在自然定义域上连续；闭区间上连续函数取得最值。

STATION 01 · p.3–9

The real line and bounds实数线与上下界

Use intervals to describe membership, then distinguish upper bounds, suprema and maxima by asking where the best boundary lies and whether it belongs to the set.

先用区间回答“集合里有什么”，再用 sup 与 max 回答“最好的界在哪里，是否真的属于集合”。

定义 1.1–1.11

集合运算

A ∪ B: at least one; A ∩ B: both; A ∖ B: in A and not in B.

证明两个集合相等，最稳妥的动作是证明 A ⊆ B 与 B ⊆ A。De Morgan 律只是“不属于并/交”的逐项翻译。

上界与最大值

sup A is the least upper bound; max A is an upper bound that belongs to A.

sup A 可以不在 A 中，max A 必须在 A 中。所以 (0, 1) 有 sup = 1，却没有最大值。

三角不等式：为什么总误差可以拆开

正向：|x + y| ≤ |x| + |y|。证明极限唯一性和把总误差拆成两半时都会用到它。

反向：||x| − |y|| ≤ |x − y|。它用来证明一个量最终远离零，例如分母不会太靠近 0。

它通常是“不超过”，不是等号。取 x = 1，y = −1，左边为 0，右边为 2。

STATION 02 · p.10–15

Functions and countability函数与可数性

A function is determined by its domain, codomain and rule. Changing the domain or codomain changes the properties of the same rule x ↦ x².

函数由定义域、陪域和规则共同决定。改变定义域或陪域，同一个 x ↦ x² 的性质会变化。

切换 x² 的定义域和陪域，观察单射、满射、双射如何变化。

像与原像

f(E) asks where inputs go; f⁻¹(F) asks which inputs land in F.

原像 f⁻¹(F) 总是可以定义；它不要求 f 有逆函数。f 在 R 上不是单射，但 [0, 4] 仍然可以有原像 [−2, 2]。

可数性

A is countably infinite if there is a bijection f : N → A.

无限不等于不可数。Z 可以按 0, 1, −1, 2, −2, ... 编号；R 不能这样列出。

像与原像的快速对照

查看像：取 E = [−2, 1]，x² 的最小值是 0，最大值是 4，所以 f(E) = [0, 4]。

查看原像：F = [0, 4] 时，所有满足 0 ≤ x² ≤ 4 的输入是 [−2, 2]。

可数：N、Z、Q 都可数；R 不可数。可数集合包括有限集和与 N 双射的无限集。

复合函数与自然定义域

(g ∘ f)(x) = g(f(x))，先做 f，再做 g；复合顺序通常不能交换。

根号要求被开方式非负，对数要求真数为正，分母要求不为零。所有限制必须同时满足。

(x² − 1)/(x − 1) 可以约成 x + 1，但原函数仍在 x = 1 缺失定义；约分不会自动补回这个点。

!

高频漏洞：看见 f⁻¹(F) 就以为 f 有逆函数。原像只是一个集合问题，不是“每个输出只能对应一个输入”。

即时检查：x² 作为 R → R 的函数，具有哪些性质？

能用 f(1) = f(−1) 解释为什么 x² 不是单射，就算完成本节。

STATION 03 · p.16–26

Sequence limits: the whole tail must settle数列极限：整条尾部一起靠近

Epsilon is the output tolerance and N is the starting index. N may depend on epsilon, but once chosen it must control every term with n ≥ N.

epsilon 是输出容差，N 是起始下标。N 可以依赖 epsilon，但选定以后必须覆盖所有 n ≥ N。

定义 2.1–2.22

实验：epsilon-N 容差带

量词结构：∀ε > 0，∃N，∀n ≥ N：|aₙ − L| < ε。前两个选择完成以后，第三个条件必须覆盖全部下标。

收敛与有界

Convergent ⟹ bounded, but bounded does not imply convergent.

(−1)ⁿ 被限制在 [−1, 1] 内，却一直来回跳，所以有界不推出收敛。

夹逼与运算

If aₙ ≤ bₙ ≤ cₙ eventually and aₙ, cₙ → L, then bₙ → L.

夹逼必须让三条不等式同时发生在同一个尾部。极限法则则先把复杂表达式拆成已知极限。

!

高频漏洞：“有无限多项进入容差带”不等于“最终所有项都在容差带里”。量词里的 ∀n ≥ N 不能删。

即时检查：若 aₙ 有界，可以推出 aₙ 收敛吗？

能把 epsilon-N 定义读成“最终整条尾部进入容差带”，就算完成本节。

STATION 04 · p.27–34

Function limits: input neighbourhoods control output error函数极限：输入邻域控制输出误差

An accumulation point makes taking a limit meaningful. Epsilon controls output error, delta controls input distance, and the punctured limit ignores f(a).

先有聚点，再去掉 x = a。epsilon 管输出，delta 管输入；f(a) 是否存在不改变去心极限。

实验：epsilon-delta 双向容差

调节 ε 和 δ，观察水平输出带与竖直输入带。判定只看去心邻域里的点。

聚点为什么必须出现

For every δ > 0, there exists x ∈ D with 0 < |x − a| < δ.

如果没有定义域中的点任意靠近 a，极限定义可能因为“没有 x 可检查”而空洞成立。

代入与约分

Substitution is justified when the limiting denominator is non-zero.

0/0 时不能直接使用商法则。约分只在去心邻域上合法，不能偷偷补回原函数缺少的点。

!

高频漏洞：极限存在不等于函数在该点有定义；f(a) 的值也不参与去心极限的计算。

即时检查：函数极限 lim x→a f(x) 会受 f(a) 的值影响吗？

能解释 0 < |x − a| 为什么排除点值，就算完成本节。

STATION 05 · p.34–43

Continuity: matching the limit to the point value连续性：极限与点值握手

Continuity is not merely “the graph looks connected.” Three facts must hold: f(a) exists, the two-sided limit exists, and the limit equals f(a).

连续不是“图像不断开”的口头描述，而是三件事同时成立：函数在 a 有定义、极限存在、极限等于 f(a)。

连续与去心极限

f is continuous at a if and only if lim x→a f(x) = f(a), when a is an accumulation point of D.

连续允许 x = a，因为那里 |f(a) − f(a)| = 0；去心极限刻意排除 a，只观察附近行为。

序列刻画

Every xₙ → a in D must satisfy f(xₙ) → f(a).

证明连续需要所有趋近序列；反驳连续只要找到一个坏序列。跳跃函数从左右两侧趋近会得到不同输出。

连续函数的标准性质

和、差、积以及分母不为零的商仍连续；复合函数在内层点与外层对应点都连续时连续。

初等函数在自然定义域上连续。闭区间上的连续函数有界并取得最大值与最小值。

连续且严格单调的函数在像区间上存在连续、严格单调的逆函数。

无穷处极限与无穷极限

x → ∞：输入超过任意阈值后，输出必须落在 L 的任意 ε 邻域内。例如 1/x → 0。

f(x) → +∞：输出会超过任意水平 M。例如 x → 0 时 1/x² → +∞；1/x 在左右两侧分别发散到 −∞ 与 +∞。

∞ 不是实数。像 ∞ − ∞、∞/∞ 这样的形式必须继续化简，不能直接当数值相减或相除。

!

高频漏洞：“极限存在”只是连续性的第二项。还必须知道函数在 a 有定义，并且这个极限正好等于 f(a)。

即时检查：可去间断中，极限存在但 f(a) ≠ 极限。它连续吗？

能逐项检查“有定义、极限存在、二者相等”，就算完成本节。
